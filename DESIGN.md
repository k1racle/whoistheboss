# DESIGN.md — Дизайн-система «Кто здесь главный?»

Документ фиксирует дизайн-токены и правила для нового публичного слоя на `Nuxt 4` + `Tailwind CSS 4`. Источник правды — реальные токены legacy-вёрстки из `migration_old/server/styles/main.css` и шрифтовые файлы из `public/fonts/`.

## 1. Бренд

- **Продукт:** «Кто здесь главный?» — премиальный медиа-портал о предпринимателях и их бизнесе.
- **Позиционирование:** деловой журнал в духе Forbes × The Verge.
- **Визуальный тон:** белый/светлый фон, много воздуха, один терракотовый акцент.
- **Основной цвет:** `#DB2A00` (терракота).
- **Основной шрифт:** Dexa Pro.
- **Приоритет вёрстки:** mobile-first, адаптивность до десктопа (до 1920px).

## 2. Цветовая система

### 2.1. Токены

| Токен | Значение | Назначение |
| --- | --- | --- |
| `accent` | `#DB2A00` | Фирменный цвет, акцент, CTA, hover, выделения |
| `bg` | `#E5E5E5` | Базовый фон страницы |
| `surface` | `#FFFFFF` | Карточки, панели, формы |
| `text` | `#070707` | Основной текст |
| `text-muted` | `#959595` | Вторичный текст, подписи |
| `border` | `rgba(7, 7, 7, 0.18)` | Границы на светлом фоне |
| `border-strong` | `#D1D1D1` | Границы карточек и разделители |
| `surface-invert` | `#070707` | Инвертированные поверхности (тёмные блоки) |
| `text-on-accent` | `#FFFFFF` | Текст на акценте и тёмных поверхностях |

### 2.2. Правила использования акцента

- Акцент `#DB2A00` используется точечно: ссылки, кнопки, стрелки, hover-состояния, номера/индексы, выделения.
- Не заливать акцентом крупные фоновые области целиком.
- На акценте — только белый текст.
- Текст никогда не пишется акцентным цветом для длинных абзацев (только короткие строки/цифры).

## 3. Типографика

### 3.1. Семейства и файлы

| Семейство | Начертания | Файлы (`public/fonts/`) | Применение |
| --- | --- | --- | --- |
| `DexaPro` | 400, 700 | `DexaPro-400-Regular.otf`, `dexapro-bold.otf` | Основной текст, навигация, кнопки, подписи |
| `DexaProCondensed` | 400, 900 | `DexaPro-Condensed-400-Regular.otf`, `DexaPro-Condensed-900-Black.otf` | Заголовки, display-тексты, marquee, крупные номера |

### 3.2. База

- Тело и интерактивные элементы: `DexaPro`, `16px`, `line-height 16px` (плотный деловой стиль), `letter-spacing 0`.
- Заголовки: `DexaProCondensed`, `font-weight 900`, `text-transform: uppercase`.
- Display-заголовки: отрицательный letter-spacing от `-0.03em` до `-0.05em`.
- Размеры заголовков задаются через `clamp()` — fluid-типографика.

### 3.3. Масштаб (эталонные значения)

| Роль | Размер |
| --- | --- |
| Display / hero | `clamp(6rem, 16vw, 20rem)` |
| Крупный заголовок секции | `clamp(3rem, 7vw, 6rem)` |
| Заголовок блока | `clamp(3rem, 3.8vw, 6rem)` |
| Заголовок карточки | `clamp(2.45rem, 2.75vw, 3.2rem)` |
| Заголовок FAQ | `clamp(56px, 16vw, 80px)` |
| Strong-строки (верхний регистр) | `32px / 32px`, tracking `-1.25px` |
| База | `16px / 16px` |
| Мелкий текст | `14px` |

## 4. Компоновка

- **Контейнер:** `width: min(100%, 1920px)`, `margin: 0 auto`.
- **Отступы секции:** `padding: clamp(4rem, 8vw, 8rem) clamp(1.25rem, 2.6vw, 2.5rem)`.
- **Хиро и полноэкранные блоки:** `min-height: 100vh` / `height: 100vh`.
- **Мобильные боковые отступы:** `10px`–`16px`.
- **Сетка:** flex/grid на усмотрение фичи; стандартный шаг между карточками `10px`–`24px`.

## 6. Ключевые компоненты

- **Кнопка (red-button):** фон `#DB2A00`, текст `#FFFFFF`, верхний регистр, `DexaPro` 16px.
- **Карточка:** фон `#FFFFFF`, граница `1px solid #D1D1D1`, индекс/номер акцентным цветом, стрелка-маска.
- **Marquee:** непрерывная строка на `DexaProCondensed` 900, длительность `72s` (desktop) / `36s` (mobile).
- **Header:** фиксированный, фон = фон страницы, логотип + навигация + CTA «Съёмка».
- **Секция FAQ:** аккордеон с белыми карточками и границей `#D1D1D1`, номер колонки, uppercase-вопрос.
- **Инвертированные блоки:** фон `#070707`, текст `#FFFFFF`.

## 7. Токены для Tailwind 4

Справочный блок для `app/assets/css/main.css` (подключение через `@import "tailwindcss";`):

```css
@import "tailwindcss";

@theme {
  --color-accent: #db2a00;
  --color-bg: #e5e5e5;
  --color-surface: #ffffff;
  --color-text: #070707;
  --color-text-muted: #959595;
  --color-border: rgba(7, 7, 7, 0.18);
  --color-border-strong: #d1d1d1;
  --color-text-on-accent: #ffffff;

  --font-sans: "DexaPro", system-ui, sans-serif;
  --font-display: "DexaProCondensed", "Arial Narrow", sans-serif;
}
```

### 7.1. Правила применения

- Utility-first: интерфейс собирается из утилит, а не из BEM-классов.
- Заголовки: `font-display font-black uppercase tracking-tight`.
- Акцент только через `text-accent`, `bg-accent`, `border-accent` и т.п. — без хардкода hex в компонентах.
- Допускаются только локальные semantic-обёртки, если они реально уменьшают дублирование.
- Шрифты подключаются через `@font-face` в `app/assets/css/main.css` с путями из `public/fonts/`.

## 8. Accessibility и поведение

- На акценте — только белый текст (контраст не ниже 4.5:1 для текста).
- Фокус-состояния интерактивных элементов обязательны.
- `scroll-behavior: smooth` включён на уровне документа.
- `::selection` использует акцентный цвет.
